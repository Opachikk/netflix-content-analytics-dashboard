# Netflix Content Analytics Dashboard

This project analyzes Netflix's catalog of movies and TV shows using Power BI.

Dataset: 8,800+ Netflix titles

## Dashboard Insights
• Movies make up ~70% of Netflix content
• United States produces the most Netflix titles
• TV-MA is the most common content rating
• Netflix experienced rapid content growth after 2016

## Tools Used
Power BI
Power Query
Data Visualization
